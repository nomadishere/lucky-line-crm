# Lucky Line CRM

Team CRM for Lucky Line Roofing (Montana). Sign in at https://nomadishere.github.io/lucky-line-crm/

All customer data lives in a private database behind the login. This repo holds only the app code.

- `index.html` – the app (Today, Pipeline, Jobs, People, Inspect)
- `x-core.js` – Calendar, Reports, Automations, Invoices, Settings, Export, Team, Add-ons
- `x-job.js` – job extras: e-sign link, scheduling, satellite measuring + materials, photos/docs, invoices, texts
- `x-voice.js` – hands-free voice commands
- `proposal.html` / `invoice.html` – the customer-facing pages (Lucky Line house style), opened by private links
- `sw.js` + `manifest.webmanifest` – install to home screen
